1. 方案一（S1 连绵瓦浪）延展 —— 逐条设计推导

命名约定（回应你上一稿的疑问）：每一条推导里的 (做法①)(做法②) 只是该条问题内部为满足"≥2 比较方案"而并列的两种小做法，做完这条就作废、下一条重新编号，与方案级无关。方案级的名字只有三个：方案一 S1（瓦屋面主形，小砚已锁）、突破三角 A案（瓦屋面框架内破三角，合规）、突破三角 B案（几何折叠/挖洞/穿插，需变更单）。旧稿里出现的"甲/乙"就是这里的"做法①/做法②"，容易和方案级混淆，本稿已统一改名。

1.1 三角发酵院是否成立（对应 §7 成立性）

  • 输入依据：三边=酿造边(2/5/6/8/3)、工坊边(13-17/1D)、酒馆边(18/10/3)；中庭为交汇场（§7.1）。航拍显示山谷为天然三岔，中央有真实交汇场。
  • 设计目标：三条真实功能边直接面对同一中庭，非背墙/长通道/仓库背面（§7.2 第24条）。
  • 比较方案：(做法①) 正三角紧凑院——中庭净空仅半径约2.0–2.4m（局部0.97m，历史数据）；(做法②) S1 连续瓦屋面统摄下的微展开三角——三边沿山谷三臂略微外拉，中庭净空放大到可站人（假设半径≥4m，待平面量取）。
  • 选择/放弃：选(做法②)。(做法①)中庭过挤，出酒日20–30人无法容纳、热酒糟穿庭与生产交汇冲突；(做法②)在不破坏三边直接对中庭的前提下解决聚人，符合§7.3"中庭是交汇场不是装饰庭院"。
  • 风险/待复核：中庭最终净空须由《三人运营看顾图》+平面量取确认（建筑）；三边直接界面是否有背墙/宽通道须出《朝中庭立面展开图》（建筑）。

1.2 三人日常运营是否成立（对应 §6.4 / §11.4）

  • 输入依据：A生产位(火灶/湿区/摊晾/白酒发酵/果酒设备)、B工坊位(灌装后端/贴标/包装/成品/账目)、C酒馆/接待位(小酒馆/厨房/中庭/公卫)（§6.4）。
  • 设计目标：三人可互看、互喊、快速支援；重物路径短（§0 总原则7、G25）。
  • 比较方案：(做法①) 三位分处三翼端头——看顾距离长；(做法②) 三位站位贴中庭三角顶点，视线交汇于中庭——最远直线距离最短。
  • 选择/放弃：选(做法②)，符合§7.2 第29条"酒馆座位同时感知中庭和生产；工坊人员抬头看见中庭"。
  • 风险/待复核：三人站位、视线、最远喊话距离、遮挡须出《3人日常运营看顾图》（§11.4，缺此图视为未完成运营校核）。

1.3 功能基底可靠性（对应 §8 编号 / §9 面积 / 附录B 动线）

  • 1号综合仓储是否完整：须含 1A粮仓/1B白酒中转/1C空瓶包材/1D洁净灌装/1E隐蔽杂物，有外部货运口+内部取用口，不拆成无统筹碎片（§8）。S1 处理：靠山侧毛石厚墙体量承载1号，外墙开外部货运口，内墙短接生产。

1.4 屋顶主形（S1 的核心，对应 §12.2）

  • 设计目标：一套连续深檐瓦屋面统摄三边；屋面起伏只由火灶排烟、跨度、地形、采光、净高、排水产生（§12.2 屋面起伏），禁无依据"瓦浪"。
  • 比较方案：(做法①) 均匀连续单坡；(做法②) 功能分段深檐——酿造边脊高(排烟/跨度需要)、工坊边中、酒馆边压低亲人，每段高差有真实理由。（0802 修订：脊高不再取假设值，改由「檐口恒 2.70m ＋ 瓦坡 1:2.2 ＋各边跨度」反推为 6.15／5.70／5.34m，全部在 6.6m 控高线下——见 §9.2）
  • 选择/放弃：选(做法②)。回应§12.2"酒馆边尺度亲人可开敞""火灶节点可适当抬高但由天锅/烟道/围观距离推导"；避免为效果图造波浪（§18）。
  • 风险/待复核：脊高须由《关键剖面》+设备推导（建筑+结构+设备）复核；檐口 2.70m 与瓦坡 1:2.2 已是 R10/R11 锁定值，不是待定项（0802 更正：本文件原写"不先锁定"有误，见 §9.2）；聚人檐净深≥3.5–4m 为历史共识G30，工作模型现取朝中庭挑 3.0m／净深 3.55m，仍须剖面校核。

1.5 火灶与排烟（对应 §12.2 火灶节点 / §16.2 暖通）

  • 输入依据：3号体验火灶蒸馏出酒/围灶/约30人活动；地面易冲洗，近厨房和公卫/呕吐区（§8 编号3）。生产柴火灶（6号）是否保留待定（§17）。
  • 设计目标：火灶节点可抬高，但高度由天锅、烟道、补风、排热、消防边界、围观距离决定（§12.2）。
  • 比较方案：(做法①) 火灶脊单独高耸成造型标志；(做法②) 火灶抬高只到排烟/补风所需，不做造型化尖顶。
  • 选择/放弃：选(做法②)，避免§18"把火灶做成造型标志"之嫌；符合§12.5"夜态只亮酒馆与火灶，不做亮化"。
  • 风险/待复核：火灶剖面+排烟路径+安全边界须暖通/消防专项（§16.2）；明火+蒸馏酒精蒸汽是消防重点，越早接入越省（分段路线图卡点）。

1.6 靠山毛石界面（对应 §12.3 材料 / §16.2 地勘）

  • 输入依据：毛石用于靠山、陈酿、仓储、墙裙或必要挡护；幕阜山复式花岗岩，糙砌乱砌不细凿（§12.3、共识G29）。落石带需防护退让（场地实况：悬空高1.1–9m 数十处）。
  • 设计目标：毛石回答承重/挡土/围护还是饰面之分工，及防潮/排水/落石防护（§12.3 必须回答）。
  • 比较方案：(做法①) 毛石仅做饰面贴皮；(做法②) 毛石做承重挡土厚墙承载1号仓储/20号陈酿稳定界面。
  • 选择/放弃：选(做法②)，符合"石为芯"，兼顾恒温与靠山稳定；但不把日常高频生产推入山体深处（§12.2 靠山边）。
  • 风险/待复核：地基、挡土、落石、崖壁风化须地勘/边坡/结构专项（§16.2），本组不代签。

1.7 深檐与气候（对应 §4.4 / §16.1）

  • 输入依据：冬至谷底直射0–3h（南部0–1h）、夏至7–9.8h暴晒；年降水1283mm、积雪按10cm、冻融（共识G27/G28）。

  • 风险/待复核：檐深须叠加真实坐标、地形、树木遮挡与日照/雨飘/风环境复核，不直接套固定值（§4.4）；须出《冬至/夏至日照斑块图》（分段路线图第二段）。

2. 突破三角 · A 案（合规）—— 设计推导 + 逐条对照 v2.1

一句话：保留"连续深檐瓦屋面 + 毛石"为主形材料，把规整正三角打散成顺山谷三条真实臂放射的"三功能边围合一个中庭"构型；破的是"三角形状"，守的是"三真实功能边直对同一中庭"（§7 允许甚至要求：三角发酵院≠三角形轮廓）。折叠/挖洞/穿插只发生在瓦屋面体量与院墙上，每处都有功能理由。不改写任何锁定项，不需要变更决定单，可直接推进。

与 S1 的区别（一句话）：S1 是"微展开三角"（三边略外拉、几何仍近三角）；A 案更进一步，把三边索性拆成顺谷三臂的放射折线，中庭从"三角内切"变成"三臂交汇的敞口场"。二者同属瓦屋面语言，A 案是 S1 在平面几何上的"突破版"。

以下按《总体任务书》§3.3 强制格式逐条推导。凡与 §1 S1 结论一致处注明"同 §1.x"，仅展开 A 案因破三角而变化的部分。

2.1 破三角后"三功能边围合一个中庭"是否仍成立（§7 成立性）

  • 输入依据：航拍显示山谷本身为天然三岔放射，中央有真实红土交汇场，三臂向外辐射（这是 A 案的第一手场地依据，不是凭空造型）。三边=酿造边/工坊边/酒馆边同 §1.1。
  • 设计目标：抛弃正三角"闭合内切"的紧，改为三臂顺真实地形张开，但三条功能边仍直接面对同一中央交汇场（§7.2 第24条），不得退化成"一条长街"或"背对中庭"。
  • 比较方案：(做法①) 正三角原型——中庭闭合但过挤（同 §1.1 痛点）；(做法②) 三臂顺谷放射——三边沿山谷三条真实臂展开，中庭是三臂交汇的敞口场，净空显著放大（假设三臂夹角约 100–130°，中庭可容 20–30 人，待平面量取）。

  • 同 §1.8/2.8：中庭为下沉/平院，无永久大伞。B 案特有：下沉院自带围合遮蔽，夏季比敞口放射院更凉，但排水/防涝是重点（下沉院易积水）。

3.9 结构与跨度：挖洞/穿插的承重现实（§17 / §19.4）—— 回应你"符合真实承重/安全/物理"

  • 输入依据：你明确要求挖洞/穿插必须"符合真实世界物理、承重、安全"。
  • 设计目标：挖出的洞口、穿插条与主体的交接，必须结构成立、不是画上去的。

  • 选择/放弃：B 案在概念上成立的前提是这些转换全部由结构专项落实；本 AI 组只提出接口与问题，不代签"可建"（§17、§0 总原则13）。
