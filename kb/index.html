这份东西把七轮材料拆成三层，层与层之间不重复：第一层「始终共识」是从未被推翻的判断，共 38 条，是给设计方看的红线；第二层「历次沟通」只记每轮新增、改变、否掉了什么，是变化的账；第三层「账不平的地方」把互相打架的条目摆出来，不替甲方裁决。

去重规则一句话：一件事只在它第一次成立的地方出现一次。

一始终共识 38 条（红线）

立场与判断顺序　G01–G06

G01｜这是一个真实生产的作坊，不是展示酒文化的场馆。一切空间首先要能干活。"一间工坊首要是承担功能性需求……其次做好看应该是最不难达到的需求。"
G02｜判断顺序不可颠倒：先推演动作，再生成空间。正确：先确认三个人怎么运营 → 高频生产动作 → 哪些功能必须互相看见 → 压缩合并贴边 → 最后才决定什么需要山体承接。
错误：先保留建筑形态 → 把功能分散进去 → 放不下就挖洞 → 动线远了就解释成"体验路径"。
G03｜"没有桃花源"是小有天成立的反向起点。"小"是反宏大、反傲慢、反景区化；"有天"是在人间苦处保留一点能安顿自己的缝隙。不做仙境，做缝隙。
G04｜立面与形态是运营的结果，不是造型的起点。形式不得为了自身牺牲生产动线。
G05｜奇观要少而准，商业是结果不是起点。外表是龙门客栈的江湖气，内里是没有神像的庙。
G06｜十不能。不能成为：野奢酒店的附属酒吧／漂亮但冷的乡建／网红打卡景区／个人崇拜馆／大型商业综合体／疗愈课程中心／工业酒厂／被导览牵着走的参观线／靠亮化撑气氛的夜景／靠表演维持的"体验"。

运营与人　G07–G12

G07｜日常三人可看顾，扩展最多五人。所有面积、动线、设备位置都按这个人数倒推。
G08｜看得见、叫得应。"我需要在场地内，大家彼此望得见，叫得应。"这是小有天特有的空间指标，需要专门的人声可达图来校核。
G09｜中庭尺度的上限，是提高声音能听见。"人站在一边，正常提高声音，另一边能听见。如果要靠吼，就太大。"
G10｜30 人不挤，3 人不空。出酒日峰值 20–30 人，日常 3 人＋3–5 访客。同一组空间要同时承住这两种状态。
G11｜人与人之间要留出"一个可以拔刀的距离"。"我对人群密集待一起有不适感。"广场不做成一大片空场，要用树、低墙、石块、水渠、台阶切成停留岛。
G12｜三条底线的优先顺序：访客不被打搅 ＞ 在地工作人员最小工作量 ＞ 访客美好的现场体验。三者相冲时按此顺序取舍。运营要轻型、可交接、可复用。

生产与动线　G13–G20

G13｜总纲：湿区共用，发酵分开，火灶开放，后端归工坊。
G14｜白酒重物核心闭环（5-6-4-2-3）必须短、平、可推车、无门槛。湿区 → 生产火灶 → 摊晾拌麯 → 白酒发酵间 → 体验火灶蒸馏。"这里每一步都是重物，不是游客散步。"一百斤米泡后变一百四五十斤。
G15｜重物少走路是硬指标，不是体验修辞。主推车通道 ≥1.2m（舒适 1.5m）；掉头 ≥1.5m（最好 1.8m）；重要门宽 ≥1.2m；门槛不允许；地面防滑可冲洗；排水沟不得横切推车主线；重物线尽量同标高。不做全场滑索，改固定吊点＋短单轨＋葫芦＋升降倒料车。"不是炫技，而是救工人的腰。"
G16｜货运不穿中庭，1 号必须有独立外部货运口。"酒瓶都是按托购买，如果只能走小拖车，那以后每一托都要拆散……增加破碎风险也会增加很多人力成本。"
G17｜白酒发酵与果酒发酵不得合并；果酒装瓶灭菌区不得靠近柴火。前端湿区可共用，工具筐具容器分开。
G18｜包装、贴标、打包、发货统一归工坊，不放在酿造湿区内。
G19｜火灶区是出酒舞台，三层圈层不得混。核心操作圈只允许工人；访客体验圈可看蒸馏打热酒围灶；廊下停留圈是访客主要停留区。
G20｜清水、灰水、酒糟废水、果渣废水必须工程分流。"否则后期会臭。"

观看与边界　G21–G26

G21｜白酒发酵间的目标状态：看得见，闻得到，问得到，但摸不到。可看不可进；不做玻璃顶、不做俯视展厅。
G22｜访客是"可观看、轻参与、不干扰"，不是"被导览"。
G23｜三层边界同时存在：视觉边界、卫生边界、动线边界。低栏杆、半墙、木格栅、观察窗均可；工人操作通道与游客观看廊分开。
G24｜低压参与。访客可以只是站着看、端着酒走开，不被要求互动、消费或参与。
G25｜任意两个站位之间，隔的不该超过一道半透边界。只有发酵间和果酒洁净区需要封闭，其它用矮墙或架子区隔。减少大走廊，不要在走廊下放小盒子。
G26｜热酒糟穿中庭进泡脚池，是唯一允许的表演性穿庭。其余生产动作不为观看而绕路。

场地·气候·材料　G27–G32

G27｜冬季的温暖不能靠太阳，要靠火。冬至谷底直射 0–3h（南部 0–1h）。外摆座位必须落在冬至 ≥3h 的日照斑块上；落不上的必须配火源。
G28｜夏季的凉快要靠遮，深檐与伞棚是必需品不是风格偏好。夏至 7–9.8h 直射；年降水 1283mm；极端温度 −5.2~40.2℃；积雪按 10cm；年日照 1740h。
G29｜瓦木为衣、石为芯、竹为棚、土为试。瓦木深檐为主形；毛石厚墙做靠崖体块（幕阜山复式花岗岩，糙砌乱砌不细凿）；竹构只做轻棚，需雪载冰挂验算、8–10 年更换、永不靠近火灶；夯土降级为室内隔墙与试验墙。
G30｜从滴水檐到聚人檐。聚人檐净深 ≥3.5–4m；通行段 ≥2m；檐口下沿净高 2.4–2.8m。只做滴水檐不算完成。
G31｜材料要"降一层新和净"。现在的木构太亮太新太完整，像刚开业的高端日式乡建。要选会变老得好看的材料，效果图要画"用过的状态"。场地开采的石料就地消化。
G32｜夜态只亮酒馆与火灶，不做亮化工程。

协作与交图纪律　G33–G38

G33｜责任边界。运营方确认怎么生产、怎么使用、哪些关系不能破坏；设计方负责转化为空间、面积、设备位置、工程接口和图纸，不得把设备尺寸、工程接口、面积推导全部反问运营方。
G34｜只交平面图 ＝ 未完成本轮修改。每轮必须回答"为什么这样放"。
G35｜放不下要先提交面积表，不许自行把发酵间移入山体。
G36｜0615 编号为底，不得随意改。1–20 号及子区（1A–1E／3A–3B／4A–4B／5A–5B／6A–6B／8A–8D／16A）是共同语言。
G37｜不新增未确认的新概念；先校核，后深化。形态存疑时先做《三角发酵院成立性校核图》，再做细部。
G38｜山体只承接陈酿储酒，日常高频生产不进山洞。不再增加发酵洞、不再增加复杂洞穴游线、不把白酒主发酵间放北侧山体。
